# ICT251 Web Technologies — Activity 2

## Personal Website

This project is a personal website developed as part of ICT251 Web Technologies at Mulungushi University.

The website demonstrates fundamental HTML5 and CSS concepts, including semantic structure, navigation, multimedia, tables, forms, and responsive design.

## How to Run

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if necessary.
4. Open `index.html`.
5. Click **Go Live**.

The contact form is a frontend demonstration only. It does not transmit or store submitted information.
